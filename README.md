# Advanced Python Topics

This repository is a learning portfolio for advanced Python design, architecture, and clean code practices. It is organized to help developers study real examples of SOLID principles, design patterns, low-level design, and senior-level assignment improvements.

## Repository Structure

- `Clean-Code-Practices/`
  - Examples of SOLID principles with before/after code.
  - Includes single responsibility, open/closed, Liskov substitution, interface segregation, and dependency inversion.

- `Design-Patterns/`
  - Practical pattern examples with runnable Python code.
  - Contains `adapter`, `factory`, and `observer` implementations.

- `LLD/`
  - Low-level design examples for classic games and systems.
  - Includes `chess_LLD`, `snakesandladders_LLD`, and `tictactoe_LLD`.

- `Senior SDE Improvements/`
  - Refactorings, assignments, and notes focused on senior developer skills.
  - Projects include TicTacToe, Ultimate TicTacToe, Library, Parking Lot, Stock Market, Task Scheduler, Payment System, Notification System, ride dispatch, hospital ED, and more.

## Why This Repo Is Useful

- Learn how to apply SOLID principles in real Python code.
- See design pattern implementations with executable examples.
- Explore low-level design for game systems and architectural planning.
- Review senior-level refactorings that improve structure, maintainability, and readability.
- Understand how to move from working code to clean, extensible design.

## Learning Recommendations

1. Start with `Clean-Code-Practices/SOLID-Principles` to understand core design principles.
2. Explore `Design-Patterns` to see how common patterns work in Python.
3. Read `LLD` examples to learn how to model systems and maintain clean boundaries.
4. Study `Senior SDE Improvements` to see higher-level architecture, tests, and implementation notes.

## How to Use

- Open the files in your editor and compare "before" and "after" examples.
- Run sample scripts where available (for example, `Design-Patterns/adapter/main.py`).
- Read `Senior SDE Improvements/Improvements_Over_Assignements.md` for growth notes and project reflections.

## Requirements

- Python 3.8+ is recommended.
- No additional dependencies are required for most examples.
